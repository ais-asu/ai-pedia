# Changelog

Notable changes to AI Pedia. Versions are tagged on GitHub as `vX.Y.Z`.

## 1.0.0 - 2026-09-28

First public release.

- Articles are Markdown and Jupyter notebook files in `content/`, prerendered
  at build time. No database.
- The library is shown as an interactive neural map on the home page and
  `/learn`, with a reading panel for each article.
- Cmd/Ctrl+K search, a table of contents, Copy Markdown and Edit on GitHub on
  every article.
- LaTeX math, syntax-highlighted code, allowlisted iframe embeds and embedded
  React visualizations in articles.
- Article HTML is sanitized before rendering.
- Articles: Linear Regression, and Sampling Foundations for Statistical
  Inference.
